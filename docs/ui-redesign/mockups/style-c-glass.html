知遥你好，

分享大纲我先整理了一版，你看看顺序对不对。这次我不想讲「我们做了哪些功能」，而是想讲约束如何反过来决定界面。

  • 离线时所有操作先落本地，界面立刻给反馈，而不是转圈
  • 远端写入结果未知时，绝不自动重发 —— 界面上要有一个明确的 outcome_unknown 状态
  • 加解密发生在核心层，阅读器只拿到已消毒的 HTML

第三条其实最容易被忽视：我们花了很久才让「跟踪像素」这件事在界面上变得诚实。

好的邮件客户端不该让人感到「在用软件」，而是像在读信。
