Pebble Go · UI Redesign · Concept Round 01

同一个邮箱，五种视觉人格

现有的 Pebble Go 界面沿用上游的暖白底 + 陶土色强调（#d4714e）。 下面五个方向使用完全相同的信息结构与完全相同的演示数据， 只改变视觉语言 —— 这样可以直接对比「哪种气质适合这个产品」，而不是对比功能差异。

共同结构
三栏：导航 · 列表 · 阅读器 + 顶栏 + 状态栏
共同状态
未读 / 选中 / 已加星 / 附件 / CI 失败 / 隐私拦截
共同能力
双账户、离线可用、队列与发件箱可见

五个方向

A · 推荐
静纸Quiet Paper

邮件是印刷品。暖白纸、墨色字、发丝线分隔、零阴影。颜色只留给「未读」。

字体阅读器与标题用衬线（宋体/Songti），界面用无衬线
密度中等偏紧，行高 1.55
最像纸质信笺 / Readwise Reader
克制长文友好不易疲劳淡
暖陶Warm Clay

保留品牌陶土色，但把它从「强调点」升级成「空气」：柔和渐变、大圆角、卡片浮起。

字体全无衬线，字重变化做层次
密度宽松，行高 1.6 + 大间距
最像Notion Calendar / Craft
亲和品牌延续偏软占空间
午夜玻璃Midnight Glass

深色优先的「工具感」。近黑分层、电光靛强调、等宽数字，状态灯常驻可见。

字体Inter 系无衬线 + 等宽做数据
密度紧凑，信息密度最高
最像Linear / Superhuman
专业状态透明深色偏重需配浅色版
编辑部Editorial

收件箱就是「本期目录」，列表是目次，阅读器是一栏正文。高对比衬线 + 黑色粗线 + 红色点题。

字体正文衬线 1.75，等宽做元信息
密度列表宽松，正文易读
最像报纸 / Are.na / 独立杂志
有主张阅读极佳工具感弱高对比分人
极简工具Minimal Tool

这是工具，不是杂志。单一中性灰阶、等宽数字防跳动、每屏多放三行、零装饰。

字体系统无衬线，12.5px 基准
密度最高，行高 1.5，行高 24px
最像Thunderbird / Apple Mail
高效好实现无个性不够「有温度」

我的建议

  • A（静纸）作为主体方向：它最贴合 Pebble 原本的品牌气质（纸 + 陶土色），同时把「杂」的部分去掉 —— 现有界面最大的问题是样式来源太多（内联 style + Tailwind + CSS 变量 + 硬编码 hex 混用），A 把这套收敛成 4 个色阶 + 1 个信号色，改造成本可控。
  • C（午夜玻璃）作为深色模式的形态：它的状态灯、等宽数字、队列可见性设计，正好回答「离线优先 / 结果未知」这类状态在界面上怎样才算诚实。可以把它的「状态语言」移植进 A 的深色版。
  • B、D 不建议作为主方向：B 的暖度和现有配色太接近，等于没改；D 气质很强但会把一个邮件工具变成阅读器，列表密度和操作密度都会受损。
  • E 是安全牌：如果团队想要「先别冒险，把结构做干净」，E 的改造量最小，但需要后续再补一层品牌语言。
